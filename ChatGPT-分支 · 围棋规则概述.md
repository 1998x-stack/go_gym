下面这份“围棋规则速查表”覆盖了常见对局里会用到的要点，也点出几种流行规则体系（中、日、韩/AGA）之间的差异：

### 基础与目标

*   **棋具**：19×19 为标准（也可 13×13、9×9）。黑先、白后，轮流把棋子落在**交叉点**上，一着落定不得移动。
*   **目标**：通过围地与吃子获得比对手更多的**目数**（或叫“点数”）。

### 气与提子

*   **气**：与己方棋子（同色、相邻上下左右）相连的一块棋，空着点就是这块的“气”。
*   **提子**：对方一块棋的所有气被占尽时，该块即被提走，作为己方的“提子”。
*   **打吃**：把对方某块棋的气打到只剩一口，称“打吃”。

### 自杀禁手

*   多数规则（中国、日本、韩国、AGA）**禁止自杀**：不得下在使己方某块立即无气的位置（除非同时吃掉对方而获得气）。
*   少数体系（如新西兰规则）**允许自杀**，但这不算主流。

### 劫与超级劫

*   **劫**：双方互相单提一子、立刻打回会形成局面无限循环。标准“劫禁”规定：**提劫后不得立即劫回，需在别处先应一手（打劫材）**，待对方应对后方可再劫。
*   **超级劫（Superko）**：为避免更复杂的循环，有的规则要求**不得重复出现过的整盘局面**。常见有“情景超级劫（SSK）”与“位置超级劫（PSK）”。（日、中、韩职业赛一般仅用普通劫禁；AGA 常用超级劫。）

### 终局与停着

*   **停着**：当双方都认为没有收益着时，可以\*\*“停着/过一手”\*\*。
*   **终局判定**：通常是**连续两次停着**（黑停、白也停）即终局，然后清点胜负。若一方请求继续，裁判可要求继续下到分明为止。

### 数法（中日规则差异的核心）

*   **中国数子法（面积规则）**：数**盘面上己方活棋+领地**的交叉点数，**对局中落下的每一子最终也计入面积**；提走的子不额外计分。常见贴目 **7.5**。
*   **日本/韩国数地法（领地规则）**：只数**净领地**（己方围住的空点）+**提到手里的对方棋子**；盘面上的己方子本身不计分。常见贴目 **6.5**（或 7.5，赛事而定）。
*   这两种数法下的“最佳收官手”略有不同，但**胜负一致**（除极少数构型）。

### 贴目（Komi）

*   为补偿黑先行优势，白方在终局**加上固定的贴目**，并用“半目”（.5）避免平局。
*   常见设置：**中国 7.5 目**、**日本/韩国 6.5 目**；部分赛事可能用 7.5 或 7.0/8.0 等变体。

### 让子与分先

*   **让子**：水平差距大时，由弱方执黑**先在星位放置若干让子**，然后白先行（即让子后白走第一手）。贴目的设定也会相应调整（如“让子不贴目”或“白贴还部分目数”），看赛制。
*   **分先**：固定黑先、白贴目；或改用轮换先行制（让先、授先）。

### 死活、双活与填空点

*   **活棋**：能无条件避免被提的棋形，常见判断是做出**两眼**。
*   **死棋**：无条件将被提的棋，在终局清理时按规则处理。
*   **双活/共活（Seki）**：双方互相有气、谁动谁死的共存状态，**双方都不能提对方**。在日/韩规则下，双活中的**空点不计地**；中国规则下，这些点是否计入面积取决于是否算作活棋的内部空点（通常不计）。
*   **填“劫外空”与收官**：为防止对手在你地里找劫材，收官阶段常需**把自家地里无害的空点填满**；不同数法下填与不填的收益不同。

### 打点与争议处理

*   若对**死活或边界**有争议，可按赛事细则：复盘回退到停着前、继续下到分明；或由裁判/规则中的判定法（如“寒泉法”“假石法”）裁定。

### 用时与判负

*   常见用时制：**日本读秒**（基本时长+每手固定读秒）、**加拿大读秒**（在限定时间内须完成 N 手）、**费舍尔/增益时**等。**超时判负**。
*   其他判负：**中盘认负/弃权**、**禁着点（明显违规）**、**全局重复违反超级劫**等。

```python
from __future__ import annotations
import numpy as np
from typing import List, Optional, Tuple, Iterable, Set

Color = int
EMPTY: Color = 0
BLACK: Color = 1
WHITE: Color = 2

Point = Tuple[int, int]  # (row, col)

class Board:
    """围棋棋盘与基本落子/提子/合法性判定（中国规则：禁自杀 + 普通劫禁）。

    网格用 int8：0=空, 1=黑, 2=白。
    劫：用“上一上一手棋局面”比较实现普通劫禁（不允许立即劫回）。
    """

    def __init__(self, size: int = 19, allow_suicide: bool = False, use_superko: bool = False) -> None:
        self.size = int(size)
        self.grid = np.zeros((self.size, self.size), dtype=np.int8)
        self.allow_suicide = bool(allow_suicide)
        self.use_superko = bool(use_superko)
        # 历史局面（仅在 simple-ko 用于对比上上手；在 superko 时用于全局去重）
        self.history: List[Tuple[int, bytes]] = []  # (to_play, grid.tobytes())

    # ---------- 基础工具 ----------
    def in_bounds(self, p: Point) -> bool:
        r, c = p
        return 0 <= r < self.size and 0 <= c < self.size

    def neighbors(self, p: Point) -> Iterable[Point]:
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < self.size and 0 <= nc < self.size:
                yield (nr, nc)

    def get(self, p: Point) -> Color:
        return int(self.grid[p[0], p[1]])

    def set(self, p: Point, color: Color) -> None:
        self.grid[p[0], p[1]] = color

    # ---------- 连通块与气 ----------
    def _collect_group(self, start: Point) -> Tuple[Set[Point], Set[Point]]:
        """返回（同色连通块、该块的气集合）"""
        color = self.get(start)
        assert color in (BLACK, WHITE)
        visited: Set[Point] = set([start])
        liberties: Set[Point] = set()
        stack = [start]
        while stack:
            p = stack.pop()
            for q in self.neighbors(p):
                cq = self.get(q)
                if cq == EMPTY:
                    liberties.add(q)
                elif cq == color and q not in visited:
                    visited.add(q)
                    stack.append(q)
        return visited, liberties

    def _remove_group(self, group: Iterable[Point]) -> int:
        """提子：移除给定点集；返回被提子数。"""
        cnt = 0
        for p in group:
            if self.get(p) != EMPTY:
                self.set(p, EMPTY)
                cnt += 1
        return cnt

    # ---------- 落子模拟（用于合法性/劫禁判定） ----------
    def _simulate(self, color: Color, p: Optional[Point]) -> Tuple[np.ndarray, int]:
        """拷贝棋盘并在其上模拟一手（含提子），返回（新网格、总提子数）。

        若 p 为 None 表示停着（pass），直接返回拷贝。
        """
        new_grid = self.grid.copy()
        captured_total = 0
        if p is None:
            return new_grid, 0

        r, c = p
        if new_grid[r, c] != EMPTY:
            raise ValueError("simulate: position not empty")

        new_grid[r, c] = color

        # 先检查并提掉对方无气块
        opp = BLACK if color == WHITE else WHITE
        to_capture: Set[Point] = set()
        for q in self.neighbors(p):
            if new_grid[q[0], q[1]] == opp:
                # 收集对方块的气
                group, libs = self._collect_group_on_grid(new_grid, q)
                if not libs:
                    to_capture |= group
        for q in to_capture:
            new_grid[q[0], q[1]] = EMPTY
            captured_total += 1

        # 再检查己方块是否自杀（无气且未通过提子获得气）
        group, libs = self._collect_group_on_grid(new_grid, p)
        if not libs:
            # 自杀：若禁自杀，则模拟非法
            if not self.allow_suicide:
                raise ValueError("simulate: suicide not allowed")
            # 允许自杀则保留（极少使用）
        return new_grid, captured_total

    def _collect_group_on_grid(self, grid: np.ndarray, start: Point) -> Tuple[Set[Point], Set[Point]]:
        color = int(grid[start[0], start[1]])
        assert color in (BLACK, WHITE)
        visited: Set[Point] = set([start])
        liberties: Set[Point] = set()
        stack = [start]
        while stack:
            p = stack.pop()
            r, c = p
            for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
                if 0 <= nr < self.size and 0 <= nc < self.size:
                    v = int(grid[nr, nc])
                    if v == EMPTY:
                        liberties.add((nr, nc))
                    elif v == color:
                        q = (nr, nc)
                        if q not in visited:
                            visited.add(q)
                            stack.append(q)
        return visited, liberties

    # ---------- 合法性与落子执行 ----------
    def is_legal(self, color: Color, p: Optional[Point], to_play: Color) -> bool:
        """合法性：空点、禁自杀、劫禁（普通劫；可选超级劫）"""
        try:
            # 停着永远合法（不受劫禁）
            if p is None:
                return True

            r, c = p
            if not self.in_bounds(p) or self.get(p) != EMPTY:
                return False

            new_grid, _ = self._simulate(color, p)

            # 普通劫禁：不能令局面等于“上上手”的位置（含棋盘+行棋方）
            if len(self.history) >= 2 and not self.use_superko:
                prev2_to_play, prev2_grid_bytes = self.history[-2]
                if (prev2_to_play == int(to_play)) and (new_grid.tobytes() == prev2_grid_bytes):
                    return False

            # 超级劫禁：不得重复任何已出现过的局面（含行棋方）
            if self.use_superko:
                new_sig = (int(to_play), new_grid.tobytes())
                if new_sig in self.history:
                    return False

            return True
        except ValueError:
            return False

    def play(self, color: Color, p: Optional[Point], to_play: Color) -> int:
        """执行一手。返回本手提掉对方子的数量。"""
        if not self.is_legal(color, p, to_play):
            raise ValueError("Illegal move")
        # 保存历史（当前局面签名，用于劫禁）
        self.history.append((int(to_play), self.grid.tobytes()))

        if p is None:
            return 0

        new_grid, captured = self._simulate(color, p)
        self.grid[:, :] = new_grid
        return captured

    # ---------- 查询 ----------
    def stones_count(self, color: Color) -> int:
        return int((self.grid == color).sum())

    def empty_points(self) -> Iterable[Point]:
        for r in range(self.size):
            for c in range(self.size):
                if int(self.grid[r, c]) == EMPTY:
                    yield (r, c)
```

```python
from __future__ import annotations
import numpy as np
from typing import Tuple, Set
from .board import Board, BLACK, WHITE, EMPTY, Point

def chinese_area_score(board: Board, komi: float = 7.5) -> Tuple[float, float]:
    """中国规则面积数子：得分 = 盘上活子数 + 所围空点数（中立点/共活点不计）；
    白方再加贴目 komi。
    返回：(black_score, white_score_with_komi)。
    """
    g = board.grid
    size = board.size

    # 盘上子
    black_stones = int((g == BLACK).sum())
    white_stones = int((g == WHITE).sum())

    # 领地：对每个空连通域做 flood-fill，若其邻接仅黑或仅白，则记为该方地
    visited = np.zeros_like(g, dtype=bool)
    black_terr = 0
    white_terr = 0

    def neighbors(p: Point):
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < size and 0 <= nc < size:
                yield (nr, nc)

    for r in range(size):
        for c in range(size):
            if g[r, c] != EMPTY or visited[r, c]:
                continue
            # flood 空域
            stack = [(r, c)]
            region: Set[Point] = set()
            adj_colors: Set[int] = set()
            visited[r, c] = True
            while stack:
                pr, pc = stack.pop()
                region.add((pr, pc))
                for nr, nc in neighbors((pr, pc)):
                    v = int(g[nr, nc])
                    if v == EMPTY and not visited[nr, nc]:
                        visited[nr, nc] = True
                        stack.append((nr, nc))
                    elif v in (BLACK, WHITE):
                        adj_colors.add(v)
            # 归属
            if adj_colors == {BLACK}:
                black_terr += len(region)
            elif adj_colors == {WHITE}:
                white_terr += len(region)
            # 否则是中立点/共活（不计）

    black_score = black_stones + black_terr
    white_score = white_stones + white_terr + float(komi)
    return float(black_score), float(white_score)
```

```python
from __future__ import annotations
from typing import Optional
from . import __package__ as _pkg  # silence linters
from ..core.board import Board, EMPTY, BLACK, WHITE

def render_ascii(board: Board, last_move: Optional[tuple] = None) -> str:
    """简单 ASCII 渲染。last_move 用 '()' 标注。"""
    size = board.size
    rows = []
    header = "   " + " ".join(f"{c:2d}" for c in range(size))
    rows.append(header)
    for r in range(size):
        line = [f"{r:2d} "]
        for c in range(size):
            v = int(board.grid[r, c])
            if v == EMPTY:
                ch = "."
            elif v == BLACK:
                ch = "X"
            else:
                ch = "O"
            if last_move == (r, c):
                ch = f"({ch})"
            else:
                ch = f" {ch} "
            line.append(ch)
        rows.append("".join(line))
    return "\n".join(rows)
```

```python
        2: to_play 平面（全 1 表示当前是“黑走”，全 0 表示“白走”）
        3: 上一步落子点平面（1/0）
    行动(action)：Discrete(size*size + 1)，0..N-1 表示在对应交叉点落子；最后一个索引表示 pass。
    结局：连续两次 pass 终局；胜负以中国面积数子 + komi（白加）裁定；奖励 winner 得 +1，其余 -1（和棋得 0）。
    """

    metadata = {"render_modes": ["ansi"], "render_fps": 4}

    def __init__(
        self,
        board_size: int = 19,
        komi: float = 7.5,
        allow_suicide: bool = False,
        use_superko: bool = False,
        max_steps: Optional[int] = None,
        render_mode: Optional[str] = None,
    ) -> None:
        super().__init__()
        self.size = int(board_size)
        self.komi = float(komi)
        self.allow_suicide = bool(allow_suicide)
        self.use_superko = bool(use_superko)
        self.max_steps = int(max_steps) if max_steps is not None else self.size * self.size * 2
        self.render_mode = render_mode

        self.board = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        self.to_play: Color = BLACK
        self.pass_count = 0
        self.steps = 0
        self.last_move: Optional[Point] = None

        # Observation / Action spaces
        self.observation_space = spaces.Box(low=0.0, high=1.0, shape=(4, self.size, self.size), dtype=np.float32)
        self.action_space = spaces.Discrete(self.size * self.size + 1)  # +1 for pass

        # 随机数
        self.np_random, _ = gym.utils.seeding.np_random(None)

    # ---------- Gym API ----------
    def reset(self, *, seed: Optional[int] = None, options: Optional[Dict[str, Any]] = None):
        if seed is not None:
            self.np_random, _ = gym.utils.seeding.np_random(seed)
        self.board = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        self.to_play = BLACK
        self.pass_count = 0
        self.steps = 0
        self.last_move = None
        obs = self._obs()
        info = {"action_mask": self.legal_action_mask()}
        return obs, info

    def step(self, action: int):
        assert self.action_space.contains(action), "invalid action index"
        done = False
        reward = 0.0

        # 行动解码
        if action == self.size * self.size:
            # pass
            self.board.play(self.to_play, None, to_play=self.to_play)
            self.pass_count += 1
            self.last_move = None
        else:
            r = action // self.size
            c = action % self.size
            p = (int(r), int(c))
            if not self.board.is_legal(self.to_play, p, to_play=self.to_play):
                # 非法手：给一个强信号（可按需求改为直接抛错）
                # 这里选择：非法手等价于“无效动作”：给予 -1 奖励并终局
                done = True
                reward = -1.0
                obs = self._obs()  # 不改变局面
                info = {"illegal_move": True, "action_mask": self.legal_action_mask()}
                return obs, reward, done, False, info

            captured = self.board.play(self.to_play, p, to_play=self.to_play)
            self.pass_count = 0
            self.last_move = p

        self.steps += 1

        # 切换行棋方
        self.to_play = BLACK if self.to_play == WHITE else WHITE

        # 终局判断：两次连续 pass 或步数上限
        if self.pass_count >= 2 or self.steps >= self.max_steps:
            done = True
            b_score, w_score = chinese_area_score(self.board, komi=self.komi)
            # 胜负与奖励：当前定义为“黑胜 +1，白胜 -1”；若你做自方视角训练，可在外层转换
            if b_score > w_score:
                reward = +1.0  # 黑胜
                winner = "black"
            elif w_score > b_score:
                reward = -1.0  # 白胜
                winner = "white"
            else:
                reward = 0.0
                winner = "draw"
            info = {
                "terminated_reason": "two_passes" if self.pass_count >= 2 else "max_steps",
                "score_black": b_score,
                "score_white": w_score,
                "winner": winner,
                "action_mask": self.legal_action_mask(),
            }
            obs = self._obs()
            return obs, reward, done, False, info

        obs = self._obs()
        info = {"action_mask": self.legal_action_mask()}
        return obs, reward, done, False, info

    def render(self):
        if self.render_mode == "ansi":
            return render_ascii(self.board, last_move=self.last_move)
        # 可扩展 RGB 渲染（matplotlib）

    def close(self):
        pass

    # ---------- 观察与动作掩码 ----------
    def _obs(self) -> np.ndarray:
        """返回 (4, H, W) 观测：己方、对方、to_play、last_move。"""
        g = self.board.grid
        if self.to_play == BLACK:
            own = (g == BLACK)
            opp = (g == WHITE)
            to_play_plane = np.ones_like(g, dtype=bool)
        else:
            own = (g == WHITE)
            opp = (g == BLACK)
            to_play_plane = np.zeros_like(g, dtype=bool)

        last = np.zeros_like(g, dtype=bool)
        if self.last_move is not None:
            last[self.last_move] = True

        planes = np.stack([
            own.astype(np.float32),
            opp.astype(np.float32),
            to_play_plane.astype(np.float32),
            last.astype(np.float32),
        ], axis=0)
        return planes

    def legal_action_mask(self) -> np.ndarray:
        """返回长度 N+1 的 0/1 掩码（含 pass）。"""
        mask = np.zeros(self.size * self.size + 1, dtype=np.int8)
        # pass 永远合法
        mask[-1] = 1
        for r in range(self.size):
            for c in range(self.size):
                if self.board.grid[r, c] != EMPTY:
                    continue
                if self.board.is_legal(self.to_play, (r, c), to_play=self.to_play):
                    idx = r * self.size + c
                    mask[idx] = 1
        return mask
```

设计要点（把规则→Env 的映射）
=================

*   **禁自杀**：`Board._simulate` 中若己方块无气且未通过提子获得气→判定为非法（除非 `allow_suicide=True`）。
*   **普通劫禁**：保存历史局面签名（行棋方 + 棋盘）。若新局面与“上上手”一致，则非法；可选 `use_superko=True` 时禁止重复任何已出现过的局面。
*   **两次停着终局**：`pass_count >= 2` 结束。
*   **中国面积数子**：`chinese_area_score`：得分=盘上子数+围空点；白方加 `komi`；中立/共活空点不计地。
*   **奖励**：对局结束一次性给胜负奖励（黑胜 +1 / 白胜 -1 / 和 0）。若你想“以当前执子方视角”给奖励，可在训练器中根据 `to_play` 做对称变换。
*   **动作空间**：`N*N+1`，最后一个为 `pass`。
*   **观察**：采用 4 个通道（己/敌、to\_play、last\_move），简洁且常用于策略网络输入；你也可以扩展气/打吃/合法掩码等辅助平面。
*   **信息**：`info["action_mask"]` 暴露合法动作掩码，便于策略屏蔽非法手。
*   **性能**：19×19 BFS 足够快；如需极致性能，可把连通块&气缓存或用位板优化。

> 变更要点：**simple-ko** 从对比 `history[-2]` 改为对比 `history[-1]`，并且比较的是“**落子后下一手行棋方**”与“上一条历史签名”的二元组 `(to_play_after_move, grid_bytes)`。

```python
# go_gym/core/board.py
from __future__ import annotations
import numpy as np
from typing import List, Optional, Tuple, Iterable, Set

Color = int
EMPTY: Color = 0
BLACK: Color = 1
WHITE: Color = 2
Point = Tuple[int, int]  # (row, col)

class Board:
    """围棋棋盘与基本落子/提子/合法性判定（中国规则：禁自杀 + 普通劫禁）。

    网格：int8，0=空, 1=黑, 2=白。
    劫：普通劫禁（simple-ko）对比“上一手落子前”的局面（含下一手行棋方）。
    超级劫：可选，禁止重复任意历史局面（含行棋方）。
    """

    def __init__(self, size: int = 19, allow_suicide: bool = False, use_superko: bool = False) -> None:
        self.size = int(size)
        self.grid = np.zeros((self.size, self.size), dtype=np.int8)
        self.allow_suicide = bool(allow_suicide)
        self.use_superko = bool(use_superko)
        # 历史签名：(to_play, grid_bytes) —— 追加于“执行每一步落子/停着之前”
        self.history: List[Tuple[int, bytes]] = []

    # ---------- 基础 ----------
    def in_bounds(self, p: Point) -> bool:
        r, c = p
        return 0 <= r < self.size and 0 <= c < self.size

    def neighbors(self, p: Point) -> Iterable[Point]:
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < self.size and 0 <= nc < self.size:
                yield (nr, nc)

    def get(self, p: Point) -> Color:
        return int(self.grid[p[0], p[1]])

    def set(self, p: Point, color: Color) -> None:
        self.grid[p[0], p[1]] = color

    def copy(self) -> "Board":
        """深拷贝棋盘与历史（grid bytes 可共享；bytes 本身不可变）。"""
        b = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        b.grid = self.grid.copy()
        b.history = list(self.history)
        return b

    # ---------- 连通块与气 ----------
    def _collect_group(self, start: Point) -> Tuple[Set[Point], Set[Point]]:
        color = self.get(start)
        assert color in (BLACK, WHITE)
        visited: Set[Point] = set([start])
        liberties: Set[Point] = set()
        stack = [start]
        while stack:
            p = stack.pop()
            for q in self.neighbors(p):
                cq = self.get(q)
                if cq == EMPTY:
                    liberties.add(q)
                elif cq == color and q not in visited:
                    visited.add(q)
                    stack.append(q)
        return visited, liberties

    def _remove_group(self, group: Iterable[Point]) -> int:
        cnt = 0
        for p in group:
            if self.get(p) != EMPTY:
                self.set(p, EMPTY)
                cnt += 1
        return cnt

    # ---------- 在拷贝上模拟一手 ----------
    def _collect_group_on_grid(self, grid: np.ndarray, start: Point) -> Tuple[Set[Point], Set[Point]]:
        color = int(grid[start[0], start[1]])
        assert color in (BLACK, WHITE)
        visited: Set[Point] = set([start])
        liberties: Set[Point] = set()
        stack = [start]
        while stack:
            r, c = stack.pop()
            for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
                if 0 <= nr < self.size and 0 <= nc < self.size:
                    v = int(grid[nr, nc])
                    if v == EMPTY:
                        liberties.add((nr, nc))
                    elif v == color:
                        q = (nr, nc)
                        if q not in visited:
                            visited.add(q)
                            stack.append(q)
        return visited, liberties

    def _simulate(self, color: Color, p: Optional[Point]) -> Tuple[np.ndarray, int]:
        """在副本上模拟一手（含提子），返回（新网格、被提子数）。p=None 表示 pass。"""
        new_grid = self.grid.copy()
        captured_total = 0
        if p is None:
            return new_grid, 0

        r, c = p
        if new_grid[r, c] != EMPTY:
            raise ValueError("simulate: position not empty")

        new_grid[r, c] = color
        opp = BLACK if color == WHITE else WHITE

        # 先提对方无气块
        to_capture: Set[Point] = set()
        for q in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            nr, nc = q
            if 0 <= nr < self.size and 0 <= nc < self.size and new_grid[nr, nc] == opp:
                group, libs = self._collect_group_on_grid(new_grid, (nr, nc))
                if not libs:
                    to_capture |= group
        for q in to_capture:
            new_grid[q[0], q[1]] = EMPTY
            captured_total += 1

        # 再检查己方是否自杀
        group, libs = self._collect_group_on_grid(new_grid, p)
        if not libs and not self.allow_suicide:
            raise ValueError("simulate: suicide not allowed")

        return new_grid, captured_total

    # ---------- 合法性与执行 ----------
    def is_legal(self, color: Color, p: Optional[Point], to_play: Color) -> bool:
        """合法性：空点、禁自杀、普通劫禁（或可选超级劫）。"""
        try:
            # pass 永远合法
            if p is None:
                return True
            if not self.in_bounds(p) or self.get(p) != EMPTY:
                return False

            new_grid, _ = self._simulate(color, p)
            next_to_play = BLACK if to_play == WHITE else WHITE

            # 普通劫禁：禁止“新局面(下一手行棋方) == 上一手落子前的局面签名”
            if len(self.history) >= 1 and not self.use_superko:
                prev_to_play, prev_grid_bytes = self.history[-1]
                if prev_to_play == int(next_to_play) and new_grid.tobytes() == prev_grid_bytes:
                    return False

            # 超级劫禁：禁止与任意历史签名相同
            if self.use_superko:
                new_sig = (int(next_to_play), new_grid.tobytes())
                if new_sig in self.history:
                    return False

            return True
        except ValueError:
            return False

    def play(self, color: Color, p: Optional[Point], to_play: Color) -> int:
        """执行一手。返回被提子数。"""
        if not self.is_legal(color, p, to_play):
            raise ValueError("Illegal move")
        # 记录“落子前”的签名（用于劫禁/超级劫）
        self.history.append((int(to_play), self.grid.tobytes()))

        if p is None:
            return 0

        new_grid, captured = self._simulate(color, p)
        self.grid[:, :] = new_grid
        return captured

    # ---------- 统计与枚举 ----------
    def stones_count(self, color: Color) -> int:
        return int((self.grid == color).sum())

    def empty_points(self) -> Iterable[Point]:
        for r in range(self.size):
            for c in range(self.size):
                if int(self.grid[r, c]) == EMPTY:
                    yield (r, c)

    def legal_moves(self, color: Color, to_play: Color) -> List[Optional[Point]]:
        moves: List[Optional[Point]] = [None]  # pass 永远合法
        for r, c in self.empty_points():
            if self.is_legal(color, (r, c), to_play):
                moves.append((r, c))
        return moves
```

```python
# go_gym/core/scoring.py
from __future__ import annotations
import numpy as np
from typing import Tuple, Set
from .board import Board, BLACK, WHITE, EMPTY, Point

def chinese_area_score(board: Board, komi: float = 7.5) -> Tuple[float, float]:
    """中国规则面积数子：活子 + 围空（中立/共活空不计），白方加 komi。"""
    g = board.grid
    size = board.size

    black_stones = int((g == BLACK).sum())
    white_stones = int((g == WHITE).sum())

    visited = np.zeros_like(g, dtype=bool)
    black_terr = 0
    white_terr = 0

    def neighbors(p: Point):
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < size and 0 <= nc < size:
                yield (nr, nc)

    for r in range(size):
        for c in range(size):
            if g[r, c] != EMPTY or visited[r, c]:
                continue
            stack = [(r, c)]
            region: Set[Point] = set()
            adj_colors: Set[int] = set()
            visited[r, c] = True
            while stack:
                pr, pc = stack.pop()
                region.add((pr, pc))
                for nr, nc in neighbors((pr, pc)):
                    v = int(g[nr, nc])
                    if v == EMPTY and not visited[nr, nc]:
                        visited[nr, nc] = True
                        stack.append((nr, nc))
                    elif v in (BLACK, WHITE):
                        adj_colors.add(v)
            if adj_colors == {BLACK}:
                black_terr += len(region)
            elif adj_colors == {WHITE}:
                white_terr += len(region)

    black_score = black_stones + black_terr
    white_score = white_stones + white_terr + float(komi)
    return float(black_score), float(white_score)
```

```python
# go_gym/agents/uct.py
from __future__ import annotations
from dataclasses import dataclass
from typing import Optional, Dict, Tuple, List
import math
import random

from ..core.board import Board, BLACK, WHITE, EMPTY, Color, Point
from ..core.scoring import chinese_area_score

def action_to_point(action: int, size: int) -> Optional[Point]:
    """将离散动作映射为点坐标；末位表示 pass。"""
    if action == size * size:
        return None
    return (action // size, action % size)

def point_to_action(p: Optional[Point], size: int) -> int:
    if p is None:
        return size * size
    r, c = p
    return r * size + c

@dataclass(frozen=True)
class GameState:
    board: Board
    to_play: Color
    pass_count: int
    komi: float
    last_move: Optional[Point] = None

    def is_terminal(self) -> bool:
        return self.pass_count >= 2

    @property
    def size(self) -> int:
        return self.board.size

    def legal_actions(self) -> List[int]:
        moves = self.board.legal_moves(self.to_play, self.to_play)
        return [point_to_action(m, self.size) for m in moves]

    def next_state(self, action: int) -> "GameState":
        p = action_to_point(action, self.size)
        b2 = self.board.copy()
        if p is None:
            b2.play(self.to_play, None, to_play=self.to_play)
            next_to_play = BLACK if self.to_play == WHITE else WHITE
            return GameState(
                board=b2, to_play=next_to_play,
                pass_count=self.pass_count + 1, komi=self.komi, last_move=None
            )
        else:
            b2.play(self.to_play, p, to_play=self.to_play)
            next_to_play = BLACK if self.to_play == WHITE else WHITE
            return GameState(
                board=b2, to_play=next_to_play,
                pass_count=0, komi=self.komi, last_move=p
            )

    def terminal_value_black(self) -> float:
        """终局返回黑视角价值：黑胜 +1，白胜 -1，和 0。"""
        bs, ws = chinese_area_score(self.board, self.komi)
        if bs > ws:
            return +1.0
        elif ws > bs:
            return -1.0
        return 0.0

class Node:
    """UCT 节点。存储黑方视角累计价值 total_value 与访问次数 visits。"""
    __slots__ = ("state", "parent", "children", "untried", "visits", "total_value", "action_from_parent")

    def __init__(self, state: GameState, parent: Optional["Node"] = None, action_from_parent: Optional[int] = None):
        self.state = state
        self.parent = parent
        self.children: Dict[int, Node] = {}
        self.untried: List[int] = state.legal_actions()
        self.visits = 0
        self.total_value = 0.0  # 从黑方视角累计
        self.action_from_parent = action_from_parent

    def is_fully_expanded(self) -> bool:
        return len(self.untried) == 0

    def best_child(self, c_puct: float) -> Tuple[int, "Node"]:
        """UCB1：在“当前行棋方”视角最大化。注意 total_value 存的是黑视角，需要对白方取反。"""
        best_a = None
        best_node = None
        best_score = -1e18

        # 避免除零：确保调用前所有子节点至少访问 1 次
        logN = math.log(max(1, self.visits))
        for a, ch in self.children.items():
            mean_black = ch.total_value / max(1, ch.visits)
            # 当前行棋方为白时，需要最小化黑视角 => 等价于最大化 (-mean_black)
            mean_for_player = mean_black if self.state.to_play == BLACK else -mean_black
            ucb = mean_for_player + c_puct * math.sqrt(logN / max(1, ch.visits))
            if ucb > best_score:
                best_score = ucb
                best_a = a
                best_node = ch
        assert best_a is not None and best_node is not None
        return best_a, best_node

    def expand_one(self) -> "Node":
        a = self.untried.pop(random.randrange(len(self.untried)))
        child_state = self.state.next_state(a)
        child = Node(child_state, parent=self, action_from_parent=a)
        self.children[a] = child
        return child

    def backprop(self, z_black: float) -> None:
        node: Optional[Node] = self
        while node is not None:
            node.visits += 1
            node.total_value += z_black
            node = node.parent

def default_rollout_policy(state: GameState, max_steps: int = 512) -> float:
    """随机走子直到两次 pass 或达到步数上限，返回黑视角价值。"""
    s = state
    steps = 0
    while not s.is_terminal() and steps < max_steps:
        acts = s.legal_actions()
        a = random.choice(acts)
        s = s.next_state(a)
        steps += 1
    return s.terminal_value_black()

def uct_search(root_state: GameState, n_simulations: int = 800, c_puct: float = 1.4,
               rollout_limit: int = 512) -> int:
    """在 root_state 上做 UCT 搜索，返回选择的动作（按访问次数最大）。"""
    root = Node(root_state)
    # 至少展开一个节点，避免 best_child 的除零
    if not root.state.is_terminal():
        leaf = root.expand_one()
        z = default_rollout_policy(leaf.state, max_steps=rollout_limit)
        leaf.backprop(z)

    for _ in range(n_simulations):
        node = root
        # Selection
        while not node.state.is_terminal() and node.is_fully_expanded():
            _, node = node.best_child(c_puct)
        # Expansion
        if not node.state.is_terminal() and not node.is_fully_expanded():
            node = node.expand_one()
        # Simulation
        z = default_rollout_policy(node.state, max_steps=rollout_limit)
        # Backprop
        node.backprop(z)

    # 选择访问次数最多的子节点动作
    best_a, best_vis = None, -1
    for a, ch in root.children.items():
        if ch.visits > best_vis:
            best_vis = ch.visits
            best_a = a
    # 如果还没有孩子（root 已终局），则只能 pass
    return best_a if best_a is not None else point_to_action(None, root_state.size)
```

```python
from __future__ import annotations
from typing import Iterable, Optional, Tuple

Point = Tuple[int, int]

def _sgf_coord(p: Optional[Point], size: int) -> str:
    # SGF pass 用空 []；坐标 a.. 对应 0..25
    if p is None:
        return ""
    r, c = p
    return f"{chr(ord('a')+c)}{chr(ord('a')+r)}"

def write_sgf(moves: Iterable[Tuple[str, Optional[Point]]], size: int = 19, komi: float = 7.5,
              result: Optional[str] = None,
              pb: str = "Black", pw: str = "White") -> str:
    """moves: 序列如 [("B",(r,c)), ("W",None), ...]"""
    header = f"(;GM[1]FF[4]SZ[{size}]KM[{komi}]PB[{pb}]PW[{pw}]"
    if result:
        header += f"RE[{result}]"
    body = []
    for color, p in moves:
        body.append(f";{color}[{_sgf_coord(p, size)}]")
```

```python
    parser = argparse.ArgumentParser("UCT Selfplay (Chinese rules, simple-ko)")
    parser.add_argument("--size", type=int, default=19)
    parser.add_argument("--komi", type=float, default=7.5)
    parser.add_argument("--sims", type=int, default=600, help="UCT simulations per move")
    parser.add_argument("--c_puct", type=float, default=1.4)
    parser.add_argument("--rollout_limit", type=int, default=512)
    parser.add_argument("--seed", type=int, default=0)
    parser.add_argument("--max_moves", type=int, default=None, help="safety cap")
    parser.add_argument("--sgf_out", type=str, default=None)
    args = parser.parse_args()

    random.seed(args.seed)

    board = Board(args.size, allow_suicide=False, use_superko=False)
    to_play: Color = BLACK
    pass_count = 0
    last_move: Optional[Point] = None
    moves_sgf: List[Tuple[str, Optional[Point]]] = []

    move_cap = args.max_moves or (args.size * args.size * 2)

    for t in range(move_cap):
        state = GameState(board=board.copy(), to_play=to_play, pass_count=pass_count, komi=args.komi, last_move=last_move)

        # UCT 决策
        action = uct_search(state, n_simulations=args.sims, c_puct=args.c_puct, rollout_limit=args.rollout_limit)
        p = action_to_point(action, args.size)

        # 执行
        color_char = "B" if to_play == BLACK else "W"
        moves_sgf.append((color_char, p))
        if p is None:
            board.play(to_play, None, to_play=to_play)
            pass_count += 1
            last_move = None
        else:
            board.play(to_play, p, to_play=to_play)
            pass_count = 0
            last_move = p

        # 切换
        to_play = BLACK if to_play == WHITE else WHITE

        # 终局条件：两次 pass
        if pass_count >= 2:
            break

    b, w = chinese_area_score(board, args.komi)
    diff = abs(b - w)
    if b > w:
        result = f"B+{diff:.1f}"
    elif w > b:
        result = f"W+{diff:.1f}"
    else:
        result = "0"

    print(f"Final Score — Black: {b:.1f}, White: {w:.1f} (komi {args.komi}); Result: {result}")

    if args.sgf_out:
        sgf_text = write_sgf(moves_sgf, size=args.size, komi=args.komi, result=result, pb="UCT", pw="UCT")
        with open(args.sgf_out, "w", encoding="utf-8") as f:
            f.write(sgf_text)
        print(f"SGF saved to: {args.sgf_out}")

    main()
```

```python
from __future__ import annotations
import numpy as np
from typing import List, Optional, Tuple, Iterable, Set

Color = int
EMPTY: Color = 0
BLACK: Color = 1
WHITE: Color = 2
Point = Tuple[int, int]

class Board:
    """围棋棋盘（中国规则：禁自杀 + 普通劫禁；可选超级劫）。

    - grid: int8，0空 1黑 2白
    - simple-ko: 禁止“新局面(下一手行棋方) == 上一步落子前的局面签名”
    - superko: 禁止重复任意历史局面签名（可选）
    """
    def __init__(self, size: int = 19, allow_suicide: bool = False, use_superko: bool = False):
        self.size = int(size)
        self.grid = np.zeros((self.size, self.size), dtype=np.int8)
        self.allow_suicide = bool(allow_suicide)
        self.use_superko = bool(use_superko)
        self.history: List[Tuple[int, bytes]] = []  # (to_play, grid.tobytes()) BEFORE each move

    # --- utils ---
    def in_bounds(self, p: Point) -> bool:
        r, c = p
        return 0 <= r < self.size and 0 <= c < self.size

    def neighbors(self, p: Point) -> Iterable[Point]:
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < self.size and 0 <= nc < self.size:
                yield (nr, nc)

    def get(self, p: Point) -> Color:
        return int(self.grid[p[0], p[1]])

    def set(self, p: Point, color: Color) -> None:
        self.grid[p[0], p[1]] = color

    def copy(self) -> "Board":
        b = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        b.grid = self.grid.copy()
        b.history = list(self.history)
        return b

    # --- groups & liberties ---
    def _collect_group_on_grid(self, grid: np.ndarray, start: Point) -> Tuple[Set[Point], Set[Point]]:
        color = int(grid[start[0], start[1]])
        assert color in (BLACK, WHITE)
        visited: Set[Point] = {start}
        liberties: Set[Point] = set()
        stack = [start]
        while stack:
            r, c = stack.pop()
            for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
                if 0 <= nr < self.size and 0 <= nc < self.size:
                    v = int(grid[nr, nc])
                    if v == EMPTY:
                        liberties.add((nr, nc))
                    elif v == color:
                        q = (nr, nc)
                        if q not in visited:
                            visited.add(q)
                            stack.append(q)
        return visited, liberties

    # --- simulate on copy ---
    def _simulate(self, color: Color, p: Optional[Point]) -> Tuple[np.ndarray, int]:
        new_grid = self.grid.copy()
        captured_total = 0
        if p is None:
            return new_grid, 0

        r, c = p
        if new_grid[r, c] != EMPTY:
            raise ValueError("simulate: not empty")
        new_grid[r, c] = color
        opp = BLACK if color == WHITE else WHITE

        # capture opponent groups with no liberties
        to_cap: Set[Point] = set()
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < self.size and 0 <= nc < self.size and new_grid[nr, nc] == opp:
                g, libs = self._collect_group_on_grid(new_grid, (nr, nc))
                if not libs:
                    to_cap |= g
        for q in to_cap:
            new_grid[q[0], q[1]] = EMPTY
            captured_total += 1

        # suicide check
        g, libs = self._collect_group_on_grid(new_grid, p)
        if not libs and not self.allow_suicide:
            raise ValueError("simulate: suicide not allowed")

        return new_grid, captured_total

    # --- legality & play ---
    def is_legal(self, color: Color, p: Optional[Point], to_play: Color) -> bool:
        try:
            if p is None:
                return True
            r, c = p
            if not self.in_bounds(p) or self.get(p) != EMPTY:
                return False

            new_grid, _ = self._simulate(color, p)
            next_to_play = BLACK if to_play == WHITE else WHITE

            # simple-ko: compare with previous signature
            if len(self.history) >= 1 and not self.use_superko:
                prev_to_play, prev_grid = self.history[-1]
                if prev_to_play == int(next_to_play) and new_grid.tobytes() == prev_grid:
                    return False

            # superko: forbid any repetition
            if self.use_superko:
                sig = (int(next_to_play), new_grid.tobytes())
                if sig in self.history:
                    return False

            return True
        except ValueError:
            return False

    def play(self, color: Color, p: Optional[Point], to_play: Color) -> int:
        if not self.is_legal(color, p, to_play):
            raise ValueError("Illegal move")
        self.history.append((int(to_play), self.grid.tobytes()))
        if p is None:
            return 0
        new_grid, cap = self._simulate(color, p)
        self.grid[:, :] = new_grid
        return cap

    # --- helpers ---
    def empty_points(self) -> Iterable[Point]:
        for r in range(self.size):
            for c in range(self.size):
                if int(self.grid[r, c]) == EMPTY:
                    yield (r, c)

    def legal_moves(self, color: Color, to_play: Color) -> list[Optional[Point]]:
        moves: list[Optional[Point]] = [None]
        for r, c in self.empty_points():
            if self.is_legal(color, (r, c), to_play):
                moves.append((r, c))
        return moves
```

```python
import numpy as np
from typing import Tuple, Set
from .board import Board, BLACK, WHITE, EMPTY, Point

def chinese_area_score(board: Board, komi: float = 7.5) -> Tuple[float, float]:
    """中国面积数子：活子 + 领地（中立/共活空不计），白加 komi。"""
    g = board.grid
    size = board.size

    black_stones = int((g == BLACK).sum())
    white_stones = int((g == WHITE).sum())

    visited = np.zeros_like(g, dtype=bool)
    black_terr = 0
    white_terr = 0

    def neighbors(p: Point):
        r, c = p
        for nr, nc in ((r-1, c), (r+1, c), (r, c-1), (r, c+1)):
            if 0 <= nr < size and 0 <= nc < size:
                yield (nr, nc)

    for r in range(size):
        for c in range(size):
            if g[r, c] != EMPTY or visited[r, c]:
                continue
            stack = [(r, c)]
            region: Set[Point] = set()
            adj: Set[int] = set()
            visited[r, c] = True
            while stack:
                pr, pc = stack.pop()
                region.add((pr, pc))
                for nr, nc in neighbors((pr, pc)):
                    v = int(g[nr, nc])
                    if v == EMPTY and not visited[nr, nc]:
                        visited[nr, nc] = True
                        stack.append((nr, nc))
                    elif v in (BLACK, WHITE):
                        adj.add(v)
            if adj == {BLACK}:
                black_terr += len(region)
            elif adj == {WHITE}:
                white_terr += len(region)

    b = black_stones + black_terr
    w = white_stones + white_terr + float(komi)
    return float(b), float(w)
```

```python
def render_ascii(board: Board, last_move: Optional[Point] = None) -> str:
    size = board.size
    rows = ["   " + " ".join(f"{c:2d}" for c in range(size))]
    for r in range(size):
        line = [f"{r:2d} "]
        for c in range(size):
            v = int(board.grid[r, c])
            ch = "." if v == EMPTY else ("X" if v == BLACK else "O")
            if last_move == (r, c):
                line.append(f"({ch})")
            else:
                line.append(f" {ch} ")
        rows.append("".join(line))
    return "\n".join(rows)
```

```python
from __future__ import annotations
import numpy as np
import gymnasium as gym
from gymnasium import spaces
from typing import Optional, Dict, Any, Tuple

from ..core.board import Board, BLACK, WHITE, EMPTY, Point, Color
from ..core.scoring import chinese_area_score
from ..utils.render import render_ascii

class GoChineseEnv(gym.Env):
    """Go-v1: 中国规则（面积数子、禁自杀、普通劫禁、两次pass终局）。

    Observation: (4,H,W) float32
      0: own stones (1/0) —— 相对当前行棋方
      1: opp stones (1/0)
      2: to_play plane (全1=黑走，全0=白走)
      3: last move (1/0)
    Action: Discrete(H*W+1), 最后一维为 pass
    Reward: 终局一次性给（黑胜+1/白胜-1/和0）
    Termination: 连续两次 pass 或达到 max_steps 安全上限
    """
    metadata = {"render_modes": ["ansi"], "render_fps": 4}

    def __init__(
        self,
        board_size: int = 19,
        komi: float = 7.5,
        allow_suicide: bool = False,
        use_superko: bool = False,
        max_steps: Optional[int] = None,
        render_mode: Optional[str] = None,
    ) -> None:
        super().__init__()
        self.size = int(board_size)
        self.komi = float(komi)
        self.allow_suicide = bool(allow_suicide)
        self.use_superko = bool(use_superko)
        self.max_steps = int(max_steps) if max_steps is not None else self.size * self.size * 2
        self.render_mode = render_mode

        self.board = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        self.to_play: Color = BLACK
        self.pass_count = 0
        self.steps = 0
        self.last_move: Optional[Point] = None

        self.observation_space = spaces.Box(low=0.0, high=1.0, shape=(4, self.size, self.size), dtype=np.float32)
        self.action_space = spaces.Discrete(self.size * self.size + 1)
        self.np_random, _ = gym.utils.seeding.np_random(None)

    # Gymnasium API
    def reset(self, *, seed: Optional[int] = None, options: Optional[Dict[str, Any]] = None):
        if seed is not None:
            self.np_random, _ = gym.utils.seeding.np_random(seed)
        self.board = Board(self.size, allow_suicide=self.allow_suicide, use_superko=self.use_superko)
        self.to_play = BLACK
        self.pass_count = 0
        self.steps = 0
        self.last_move = None
        obs = self._obs()
        info = {"action_mask": self.legal_action_mask()}
        return obs, info

    def step(self, action: int):
        assert self.action_space.contains(action)
        terminated = False
        truncated = False
        reward = 0.0

        if action == self.size * self.size:
            # pass
            self.board.play(self.to_play, None, to_play=self.to_play)
            self.pass_count += 1
            self.last_move = None
        else:
            r, c = divmod(action, self.size)
            p = (int(r), int(c))
            if not self.board.is_legal(self.to_play, p, to_play=self.to_play):
                # 非法手：直接给 -1 并终止（你也可以改为“无效动作不改变状态”）
                terminated = True
                reward = -1.0
                obs = self._obs()
                info = {"illegal_move": True, "action_mask": self.legal_action_mask()}
                return obs, reward, terminated, truncated, info
            self.board.play(self.to_play, p, to_play=self.to_play)
            self.pass_count = 0
            self.last_move = p

        self.steps += 1
        self.to_play = BLACK if self.to_play == WHITE else WHITE

        if self.pass_count >= 2 or self.steps >= self.max_steps:
            terminated = True
            b, w = chinese_area_score(self.board, self.komi)
            if b > w:
                reward = +1.0
                winner = "black"
            elif w > b:
                reward = -1.0
                winner = "white"
            else:
                reward = 0.0
                winner = "draw"
            info = {
                "terminated_reason": "two_passes" if self.pass_count >= 2 else "max_steps",
                "score_black": b,
                "score_white": w,
                "winner": winner,
                "action_mask": self.legal_action_mask(),
            }
            obs = self._obs()
            return obs, reward, terminated, truncated, info

        obs = self._obs()
        info = {"action_mask": self.legal_action_mask()}
        return obs, reward, terminated, truncated, info

    def render(self):
        if self.render_mode == "ansi":
            return render_ascii(self.board, last_move=self.last_move)

    def close(self):
        pass

    # --- helpers ---
    def _obs(self) -> np.ndarray:
        g = self.board.grid
        if self.to_play == BLACK:
            own = (g == BLACK)
            opp = (g == WHITE)
            to_play_plane = np.ones_like(g, dtype=bool)
        else:
            own = (g == WHITE)
            opp = (g == BLACK)
            to_play_plane = np.zeros_like(g, dtype=bool)

        last = np.zeros_like(g, dtype=bool)
        if self.last_move is not None:
            last[self.last_move] = True

        planes = np.stack(
            [own.astype(np.float32),
             opp.astype(np.float32),
             to_play_plane.astype(np.float32),
             last.astype(np.float32)],
            axis=0
        )
        return planes

    def legal_action_mask(self) -> np.ndarray:
        mask = np.zeros(self.size * self.size + 1, dtype=np.int8)
        mask[-1] = 1  # pass
        for r in range(self.size):
            for c in range(self.size):
                if self.board.grid[r, c] != EMPTY:
                    continue
                if self.board.is_legal(self.to_play, (r, c), to_play=self.to_play):
                    mask[r * self.size + c] = 1
        return mask
```

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Optional, Dict, Tuple, List
import math, random

from ..core.board import Board, BLACK, WHITE, Color, Point
from ..core.scoring import chinese_area_score

def action_to_point(action: int, size: int) -> Optional[Point]:
    return None if action == size * size else (action // size, action % size)

def point_to_action(p: Optional[Point], size: int) -> int:
    return size * size if p is None else p[0] * size + p[1]

@dataclass(frozen=True)
class GameState:
    board: Board
    to_play: Color
    pass_count: int
    komi: float
    last_move: Optional[Point] = None

    def is_terminal(self) -> bool:
        return self.pass_count >= 2

    @property
    def size(self) -> int:
        return self.board.size

    def legal_actions(self) -> List[int]:
        return [point_to_action(m, self.size) for m in self.board.legal_moves(self.to_play, self.to_play)]

    def next_state(self, action: int) -> "GameState":
        p = action_to_point(action, self.size)
        b2 = self.board.copy()
        if p is None:
            b2.play(self.to_play, None, to_play=self.to_play)
            nxt = BLACK if self.to_play == WHITE else WHITE
            return GameState(b2, nxt, self.pass_count + 1, self.komi, last_move=None)
        else:
            b2.play(self.to_play, p, to_play=self.to_play)
            nxt = BLACK if self.to_play == WHITE else WHITE
            return GameState(b2, nxt, 0, self.komi, last_move=p)

    def terminal_value_black(self) -> float:
        b, w = chinese_area_score(self.board, self.komi)
        return 1.0 if b > w else (-1.0 if w > b else 0.0)

class Node:
    __slots__ = ("state","parent","children","untried","visits","total_value","action_from_parent")
    def __init__(self, state: GameState, parent: Optional["Node"]=None, action_from_parent: Optional[int]=None):
        self.state = state
        self.parent = parent
        self.children: Dict[int, Node] = {}
        self.untried: List[int] = state.legal_actions()
        self.visits = 0
        self.total_value = 0.0   # 黑方视角累计

        self.action_from_parent = action_from_parent

    def is_fully_expanded(self) -> bool:
        return not self.untried

    def best_child(self, c_puct: float) -> Tuple[int,"Node"]:
        best_a, best_node, best_score = None, None, -1e18
        logN = math.log(max(1, self.visits))
        for a, ch in self.children.items():
            mean_black = ch.total_value / max(1, ch.visits)
            mean_for_player = mean_black if self.state.to_play == BLACK else -mean_black
            ucb = mean_for_player + c_puct * math.sqrt(logN / max(1, ch.visits))
            if ucb > best_score:
                best_score, best_a, best_node = ucb, a, ch
        assert best_node is not None
        return best_a, best_node

    def expand_one(self) -> "Node":
        a = self.untried.pop(random.randrange(len(self.untried)))
        ch_state = self.state.next_state(a)
        ch = Node(ch_state, parent=self, action_from_parent=a)
        self.children[a] = ch
        return ch

    def backprop(self, z_black: float):
        node: Optional[Node] = self
        while node is not None:
            node.visits += 1
            node.total_value += z_black
            node = node.parent

def default_rollout_policy(state: GameState, max_steps: int = 512) -> float:
    s = state
    steps = 0
    while not s.is_terminal() and steps < max_steps:
        acts = s.legal_actions()
        s = s.next_state(random.choice(acts))
        steps += 1
    return s.terminal_value_black()

def uct_search(root_state: GameState, n_simulations: int = 800, c_puct: float = 1.4, rollout_limit: int = 512) -> int:
    root = Node(root_state)
    if not root.state.is_terminal():
        leaf = root.expand_one()
        z = default_rollout_policy(leaf.state, max_steps=rollout_limit)
        leaf.backprop(z)

    for _ in range(n_simulations):
        node = root
        while not node.state.is_terminal() and node.is_fully_expanded():
            _, node = node.best_child(c_puct)
        if not node.state.is_terminal() and not node.is_fully_expanded():
            node = node.expand_one()
        z = default_rollout_policy(node.state, max_steps=rollout_limit)
        node.backprop(z)

    best_a, best_vis = None, -1
    for a, ch in root.children.items():
        if ch.visits > best_vis:
            best_vis, best_a = ch.visits, a
    return best_a if best_a is not None else (root_state.size * root_state.size)  # pass fallback
```

```python
from __future__ import annotations
import argparse, random
from typing import Optional, Tuple, List

from go_v1.core.board import Board, BLACK, WHITE, Color, Point
from go_v1.core.scoring import chinese_area_score
from go_v1.agents.uct import GameState, uct_search, action_to_point, point_to_action
from go_v1.utils.sgf import write_sgf

def main():
    ap = argparse.ArgumentParser("UCT selfplay for go-v1 (Chinese rules)")
    ap.add_argument("--size", type=int, default=19)
    ap.add_argument("--komi", type=float, default=7.5)
    ap.add_argument("--sims", type=int, default=600)
    ap.add_argument("--c_puct", type=float, default=1.4)
    ap.add_argument("--rollout_limit", type=int, default=512)
    ap.add_argument("--seed", type=int, default=0)
    ap.add_argument("--max_moves", type=int, default=None)
    ap.add_argument("--sgf_out", type=str, default=None)
    args = ap.parse_args()

    random.seed(args.seed)

    board = Board(args.size, allow_suicide=False, use_superko=False)
    to_play: Color = BLACK
    pass_count = 0
    last: Optional[Point] = None
    moves: List[tuple[str, Optional[Point]]] = []

    cap = args.max_moves or (args.size * args.size * 2)
    for _ in range(cap):
        state = GameState(board=board.copy(), to_play=to_play, pass_count=pass_count, komi=args.komi, last_move=last)
        a = uct_search(state, n_simulations=args.sims, c_puct=args.c_puct, rollout_limit=args.rollout_limit)
        p = action_to_point(a, args.size)
        clr = "B" if to_play == BLACK else "W"
        moves.append((clr, p))

        if p is None:
            board.play(to_play, None, to_play=to_play)
            pass_count += 1
            last = None
        else:
            board.play(to_play, p, to_play=to_play)
            pass_count = 0
            last = p

        to_play = BLACK if to_play == WHITE else WHITE
        if pass_count >= 2:
            break

    b, w = chinese_area_score(board, args.komi)
    diff = abs(b - w)
    result = f"B+{diff:.1f}" if b > w else (f"W+{diff:.1f}" if w > b else "0")
    print(f"Final — Black: {b:.1f}, White: {w:.1f} (komi {args.komi}) => {result}")

    if args.sgf_out:
        sgf = write_sgf(moves, size=args.size, komi=args.komi, result=result, pb="UCT", pw="UCT")
        with open(args.sgf_out, "w", encoding="utf-8") as f:
            f.write(sgf)
        print("SGF saved:", args.sgf_out)

if __name__ == "__main__":
    main()
```

```python
from __future__ import annotations
import torch, numpy as np, random
from typing import Optional

def get_device() -> torch.device:
    return torch.device("cuda") if torch.cuda.is_available() else torch.device("cpu")

def set_seed(seed: int):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)

def masked_log_softmax(logits: torch.Tensor, mask: torch.Tensor, dim: int=-1) -> torch.Tensor:
    # mask: 1=legal, 0=illegal
    very_neg = torch.finfo(logits.dtype).min
    masked = logits.masked_fill(mask == 0, very_neg)
    return torch.log_softmax(masked, dim=dim)

def masked_softmax(logits: torch.Tensor, mask: torch.Tensor, dim: int=-1) -> torch.Tensor:
    return masked_log_softmax(logits, mask, dim).exp()

def to_tensor(x, device):
    if isinstance(x, np.ndarray):
        return torch.from_numpy(x).to(device)
    return torch.as_tensor(x, device=device)
```

```python
from __future__ import annotations
import numpy as np
from typing import Dict

class ReplayBuffer:
    def __init__(self, capacity: int, obs_shape, act_dim: int):
        self.capacity = int(capacity)
        self.ptr = 0
        self.full = False

        self.obs = np.zeros((capacity, *obs_shape), dtype=np.float32)
        self.mask = np.zeros((capacity, act_dim), dtype=np.int8)
        self.act = np.zeros((capacity,), dtype=np.int64)
        self.rew = np.zeros((capacity,), dtype=np.float32)
        self.next_obs = np.zeros((capacity, *obs_shape), dtype=np.float32)
        self.next_mask = np.zeros((capacity, act_dim), dtype=np.int8)
        self.done = np.zeros((capacity,), dtype=np.int8)

    def add(self, o, m, a, r, no, nm, d):
        i = self.ptr
        self.obs[i] = o; self.mask[i] = m
        self.act[i] = a; self.rew[i] = r
        self.next_obs[i] = no; self.next_mask[i] = nm
        self.done[i] = d
        self.ptr = (self.ptr + 1) % self.capacity
        if self.ptr == 0: self.full = True

    def size(self) -> int:
        return self.capacity if self.full else self.ptr

    def sample(self, batch_size: int) -> Dict[str, np.ndarray]:
        n = self.size()
        idx = np.random.randint(0, n, size=batch_size)
        return dict(
            obs=self.obs[idx], mask=self.mask[idx],
            act=self.act[idx], rew=self.rew[idx],
            next_obs=self.next_obs[idx], next_mask=self.next_mask[idx],
            done=self.done[idx].astype(np.float32),
        )
```

```python
from __future__ import annotations
import torch, torch.nn as nn, torch.nn.functional as F

class ConvEncoder(nn.Module):
    """简单卷积编码器：输入 (B, C=4, H, W) -> (B, D)"""
    def __init__(self, in_channels=4, channels=64, depth=3, out_dim=256):
        super().__init__()
        layers = []
        c = in_channels
        for i in range(depth):
            layers += [nn.Conv2d(c, channels, 3, padding=1), nn.ReLU()]
            c = channels
        self.conv = nn.Sequential(*layers)
        self.head = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(channels, out_dim), nn.ReLU())
        self.out_dim = out_dim

    def forward(self, x):
        z = self.conv(x)
        z = self.head(z)
        return z  # (B, out_dim)

class CategoricalActor(nn.Module):
    """离散策略：输出每个动作的logits"""
    def __init__(self, in_dim: int, act_dim: int):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 256), nn.ReLU(),
            nn.Linear(256, act_dim)
        )

    def forward(self, z):  # (B, D)
        return self.net(z)  # (B, A) logits

class DoubleQCritic(nn.Module):
    """双Q：输出每个动作的 Q(s, a)"""
    def __init__(self, in_dim: int, act_dim: int):
        super().__init__()
        self.q1 = nn.Sequential(nn.Linear(in_dim, 256), nn.ReLU(), nn.Linear(256, act_dim))
        self.q2 = nn.Sequential(nn.Linear(in_dim, 256), nn.ReLU(), nn.Linear(256, act_dim))

    def forward(self, z):
        return self.q1(z), self.q2(z)
```

```python
from __future__ import annotations
import torch, torch.nn as nn, torch.nn.functional as F, math
from dataclasses import dataclass
from typing import Dict
from .nets import ConvEncoder, CategoricalActor, DoubleQCritic
from .utils import masked_log_softmax, masked_softmax, get_device

@dataclass
class SACConfig:
    gamma: float = 0.997
    lr: float = 3e-4
    tau: float = 0.005
    init_alpha: float = 0.1
    target_entropy_scale: float = 0.98  # 目标熵≈ 0.98 * E[log(#legal)]
    batch_size: int = 256

class SACDiscreteAgent(nn.Module):
    """SAC(离散)：Actor 输出 logits；Critic 输出 Q(s,·)
    - 目标：J_Q / J_pi / α 自适应
    - Soft V(s) = α * logsumexp( Q(s,a) / α )  (仅考虑合法动作)
    """
    def __init__(self, obs_shape, act_dim: int, cfg: SACConfig):
        super().__init__()
        c, h, w = obs_shape
        self.device = get_device()
        self.cfg = cfg
        self.encoder = ConvEncoder(in_channels=c).to(self.device)
        self.actor = CategoricalActor(self.encoder.out_dim, act_dim).to(self.device)
        self.critic = DoubleQCritic(self.encoder.out_dim, act_dim).to(self.device)
        self.critic_tgt = DoubleQCritic(self.encoder.out_dim, act_dim).to(self.device)
        self.critic_tgt.load_state_dict(self.critic.state_dict())
        self.alpha = torch.tensor(cfg.init_alpha, device=self.device, requires_grad=True)

        self.optim_actor = torch.optim.Adam(list(self.encoder.parameters())+list(self.actor.parameters()), lr=cfg.lr)
        self.optim_critic = torch.optim.Adam(self.critic.parameters(), lr=cfg.lr)
        self.optim_alpha = torch.optim.Adam([self.alpha], lr=cfg.lr)

    @torch.no_grad()
    def act_greedy(self, obs_t, mask_t) -> int:
        self.eval()
        z = self.encoder(obs_t.unsqueeze(0))
        logits = self.actor(z)
        probs = masked_softmax(logits, mask_t.unsqueeze(0), dim=-1).squeeze(0)
        a = int(torch.argmax(probs).item())
        return a

    def soft_value(self, q: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        # q: (B,A)  mask:(B,A)
        alpha = self.alpha.clamp_min(1e-6)
        very_neg = -1e9
        q_masked = q.masked_fill(mask == 0, very_neg)
        # α logsumexp(Q/α)
        v = alpha * torch.logsumexp(q_masked / alpha, dim=-1)
        return v

    def update(self, batch: Dict[str, torch.Tensor], step: int) -> Dict[str, float]:
        # to device
        obs = batch["obs"].to(self.device)           # (B,C,H,W)
        mask = batch["mask"].to(self.device)         # (B,A)
        act = batch["act"].to(self.device)           # (B,)
        rew = batch["rew"].to(self.device)           # (B,)
        next_obs = batch["next_obs"].to(self.device)
        next_mask = batch["next_mask"].to(self.device)
        done = batch["done"].to(self.device)

        # encode
        z = self.encoder(obs)
        z_next = self.encoder(next_obs).detach()

        # critic
        q1, q2 = self.critic(z)              # (B,A)
        with torch.no_grad():
            q1_t, q2_t = self.critic_tgt(z_next)
            q_t = torch.min(q1_t, q2_t)
            # soft V target
            v_next = self.soft_value(q_t, next_mask)
            target_q = rew + (1.0 - done) * self.cfg.gamma * v_next  # (B,)

        q1_a = q1.gather(1, act.view(-1,1)).squeeze(1)
        q2_a = q2.gather(1, act.view(-1,1)).squeeze(1)
        loss_q = F.mse_loss(q1_a, target_q) + F.mse_loss(q2_a, target_q)
        self.optim_critic.zero_grad(set_to_none=True)
        loss_q.backward()
        self.optim_critic.step()

        # actor
        logits = self.actor(z.detach())
        logp = masked_log_softmax(logits, mask, dim=-1)  # (B,A)
        probs = logp.exp()
        with torch.no_grad():
            q1_pg, q2_pg = self.critic(z.detach())
            q_pg = torch.min(q1_pg, q2_pg)
        alpha = self.alpha.clamp_min(1e-6)
        # J_pi = E_a[ α logπ(a|s) - Q(s,a) ]
        loss_pi = (probs * (alpha * logp - q_pg)).sum(dim=-1).mean()
        self.optim_actor.zero_grad(set_to_none=True)
        loss_pi.backward()
        self.optim_actor.step()

        # alpha (target entropy ~ E[log(#legal)])
        with torch.no_grad():
            target_H = self.cfg.target_entropy_scale * torch.log(mask.sum(dim=-1).clamp_min(1).float())
        loss_alpha = -(self.alpha * ( (logp * probs).sum(dim=-1).detach() + target_H )).mean()
        self.optim_alpha.zero_grad(set_to_none=True)
        loss_alpha.backward()
        self.optim_alpha.step()

        # soft update
        with torch.no_grad():
            for p, pt in zip(self.critic.parameters(), self.critic_tgt.parameters()):
                pt.data.mul_(1 - self.cfg.tau).add_(self.cfg.tau * p.data)

        return dict(loss_q=float(loss_q.item()), loss_pi=float(loss_pi.item()), alpha=float(self.alpha.item()))
```

```python
from __future__ import annotations
import math, random, numpy as np, torch
from dataclasses import dataclass
from typing import Optional, Dict, Tuple, List
from .utils import masked_softmax

@dataclass
class MCTSConfig:
    sims: int = 400
    c_puct: float = 1.5
    dirichlet_alpha: float = 0.3
    dirichlet_eps: float = 0.25
    rollout_temperature: float = 1.0  # 访问计数转策略时的温度

class Node:
    def __init__(self, parent: Optional["Node"], prior: float, player_to_move: int):
        self.parent = parent
        self.prior = prior
        self.player = player_to_move  # who will play at this node
        self.N = 0
        self.W = 0.0  # 累计“黑方视角”的价值
        self.Q = 0.0
        self.children: Dict[int, Node] = {}
        self.legal: Optional[np.ndarray] = None  # 0/1
        self.is_terminal = False
        self.reward = 0.0  # 叶子即时回报（一般围棋中间为0）

    def expand(self, priors: np.ndarray, legal_mask: np.ndarray, player_to_move: int):
        self.legal = legal_mask.astype(np.int8)
        total = (priors * legal_mask).sum()
        if total <= 0:
            probs = legal_mask / max(1, legal_mask.sum())
        else:
            probs = (priors * legal_mask) / total
        for a, p in enumerate(probs):
            if self.legal[a]:
                self.children[a] = Node(self, float(p), player_to_move)

    def ucb_score(self, child: "Node", c_puct: float) -> float:
        u = c_puct * child.prior * math.sqrt(self.N + 1e-8) / (1 + child.N)
        return child.Q + u

    def backup(self, value_black: float):
        node = self
        while node is not None:
            node.N += 1
            node.W += value_black
            node.Q = node.W / node.N
            value_black = -value_black  # 轮换视角
            node = node.parent

def run_mcts(root_obs: torch.Tensor,
             root_mask: torch.Tensor,
             root_player_black: bool,
             model,        # 提供 encoder+actor+critic 接口
             sim_env,      # 需要提供：clone()、step(a)、legal_mask()、is_terminal()、to_play_is_black()、obs()
             cfg: MCTSConfig) -> np.ndarray:
    """
    - root_obs, root_mask: (A,) legal mask for root
    - model: 需要 .encoder/.actor/.critic
    - sim_env: 必须支持在内存复制并可逆推进（我们会先克隆一个搜索用 env）
    返回：根节点访问计数策略 π(a)（np.ndarray, sum=1）
    """
    device = next(model.parameters()).device
    root = Node(parent=None, prior=1.0, player_to_move=1 if root_player_black else -1)

    # 根先验：来自 Actor
    with torch.no_grad():
        z = model.encoder(root_obs.unsqueeze(0).to(device))
        logits = model.actor(z)  # (1, A)
        priors = masked_softmax(logits, root_mask.unsqueeze(0).to(device), dim=-1).squeeze(0).cpu().numpy()

    legal = root_mask.cpu().numpy().astype(np.int8)
    # Dirichlet 掺混提升探索
    if cfg.dirichlet_eps > 0 and legal.sum() > 1:
        noise = np.random.dirichlet([cfg.dirichlet_alpha] * int(legal.sum()))
        priors_ = priors.copy()
        priors_[legal == 1] = (1 - cfg.dirichlet_eps) * priors_[legal == 1] + cfg.dirichlet_eps * noise
        priors = priors_
    root.expand(priors, legal, root.player)

    for _ in range(cfg.sims):
        # selection
        node = root
        env = sim_env.clone()
        while node.children and not node.is_terminal:
            # 选 UCB 最大的子
            best_a, best_score = None, -1e18
            for a, ch in node.children.items():
                s = node.ucb_score(ch, cfg.c_puct)
                if s > best_score:
                    best_score, best_a = s, a
            a = best_a
            env.step(a)
            node = node.children[a]
            node.is_terminal = env.is_terminal()
            if node.is_terminal:
                break

        # expand & evaluate
        if not node.is_terminal:
            obs = env.obs()                      # (C,H,W) torch
            mask = env.legal_mask()              # (A,) torch
            with torch.no_grad():
                z = model.encoder(obs.unsqueeze(0).to(device))
                # 扩展先验
                logits = model.actor(z)
                priors = masked_softmax(logits, mask.unsqueeze(0).to(device), dim=-1).squeeze(0).cpu().numpy()
                # 叶子价值：Soft-V(s)=α logsumexp(Q/α)
                q1, q2 = model.critic(z)
                q = torch.min(q1, q2)
                alpha = model.alpha.clamp_min(1e-6)
                very_neg = -1e9
                q_masked = q.masked_fill(mask.unsqueeze(0).to(device) == 0, very_neg)
                v = (alpha * torch.logsumexp(q_masked / alpha, dim=-1)).squeeze(0).item()
                value_black = v  # 约定模型价值为“黑方视角”（与训练一致）

            node.expand(priors, mask.cpu().numpy().astype(np.int8), 1 if env.to_play_is_black() else -1)
        else:
            # 终局：直接用真实奖励（黑视角）
            value_black = env.final_value_black()

        # backup
        node.backup(value_black)

    # 返回根策略 π(a) ∝ N(a)^{1/τ}
    counts = np.zeros_like(legal, dtype=np.float32)
    for a, ch in root.children.items():
        counts[a] = ch.N
    if counts.sum() <= 0:
        pi = legal / max(1, legal.sum())
    else:
        if cfg.rollout_temperature == 1.0:
            pi = counts / counts.sum()
        else:
            temp = cfg.rollout_temperature
            pi = (counts ** (1.0 / temp))
            pi = pi / pi.sum()
    return pi
```

```python
from __future__ import annotations
import torch, numpy as np
from typing import Optional, Tuple, List
from go_v1.core.board import Board, BLACK, WHITE, EMPTY, Point  # 直接用你的 go-v1 核心
from go_v1.core.scoring import chinese_area_score

def obs_from_board(board: Board, to_play, last_move: Optional[Point]):
    g = board.grid
    if to_play == BLACK:
        own = (g == BLACK)
        opp = (g == WHITE)
        to_play_plane = np.ones_like(g, dtype=bool)
    else:
        own = (g == WHITE)
        opp = (g == BLACK)
        to_play_plane = np.zeros_like(g, dtype=bool)
    last = np.zeros_like(g, dtype=bool)
    if last_move is not None:
        last[last_move] = True
    planes = np.stack([own, opp, to_play_plane, last], axis=0).astype(np.float32)
    return torch.from_numpy(planes)  # (4,H,W)

class GoSearchEnv:
    """搜索专用的“无副作用”小环境（只用 Board 复制推进），与真实 env 状态同步起点。"""
    def __init__(self, size: int, komi: float):
        self.size = size
        self.komi = komi
        self.board = Board(size, allow_suicide=False, use_superko=False)
        self.to_play = BLACK
        self.pass_count = 0
        self.last_move = None

    def sync_from(self, board: Board, to_play, pass_count: int, last_move):
        self.board = board.copy()
        self.to_play = to_play
        self.pass_count = pass_count
        self.last_move = last_move

    def clone(self) -> "GoSearchEnv":
        e = GoSearchEnv(self.size, self.komi)
        e.sync_from(self.board, self.to_play, self.pass_count, self.last_move)
        return e

    def legal_mask(self) -> torch.Tensor:
        A = self.size * self.size + 1
        mask = np.zeros((A,), dtype=np.int8)
        mask[-1] = 1  # pass
        for r in range(self.size):
            for c in range(self.size):
                if self.board.grid[r, c] != EMPTY:
                    continue
                if self.board.is_legal(self.to_play, (r, c), to_play=self.to_play):
                    mask[r * self.size + c] = 1
        return torch.from_numpy(mask)

    def obs(self) -> torch.Tensor:
        return obs_from_board(self.board, self.to_play, self.last_move)

    def step(self, action: int):
        if action == self.size * self.size:
            self.board.play(self.to_play, None, to_play=self.to_play)
            self.pass_count += 1
            self.last_move = None
        else:
            r, c = divmod(action, self.size)
            self.board.play(self.to_play, (r, c), to_play=self.to_play)
            self.pass_count = 0
            self.last_move = (r, c)
        self.to_play = BLACK if self.to_play == WHITE else WHITE

    def is_terminal(self) -> bool:
        return self.pass_count >= 2

    def to_play_is_black(self) -> bool:
        return self.to_play == BLACK

    def final_value_black(self) -> float:
        b, w = chinese_area_score(self.board, self.komi)
        if b > w: return 1.0
        if w > b: return -1.0
        return 0.0
```

```python
from __future__ import annotations
import gymnasium as gym
import torch, numpy as np
from tqdm import trange
from typing import Dict, Any

from go_v1.core.board import BLACK, WHITE, Board

def train_loop(cfg: Dict[str, Any], agent_bundle, run_name: str = "run"):
    device = get_device()
    set_seed(cfg["SEED"])

    # env
    env = gym.make("go-v1", board_size=cfg["ENV"]["board_size"], komi=cfg["ENV"]["komi"])
    obs, info = env.reset(seed=cfg["SEED"])
    C, H, W = obs.shape
    A = info["action_mask"].shape[0]

    # agent
    agent = agent_bundle.model
    sac_cfg = agent_bundle.sac_cfg
    mcts_cfg = agent_bundle.mcts_cfg
    agent.train()

    # buffer & logger
    buf = ReplayBuffer(cfg["RL"]["buffer_size"], obs_shape=(C, H, W), act_dim=A)
    logger = TBLogger(cfg["LOG"]["logdir"])

    # search env
    sim_env = GoSearchEnv(size=cfg["ENV"]["board_size"], komi=cfg["ENV"]["komi"])
    # 用内部Board镜像真实局面
    internal_board = Board(cfg["ENV"]["board_size"], allow_suicide=False, use_superko=False)
    to_play = BLACK
    pass_count = 0
    last_move = None

    global_step = 0
    episodes = cfg["RL"]["episodes"]
    steps_per_episode = cfg["RL"]["max_steps"]

    for ep in range(episodes):
        obs, info = env.reset(seed=cfg["SEED"] + ep)
        # 同步内部状态
        internal_board = Board(cfg["ENV"]["board_size"], allow_suicide=False, use_superko=False)
        to_play = BLACK; pass_count = 0; last_move = None

        ep_return = 0.0
        for t in trange(steps_per_episode, desc=f"Ep {ep}", leave=False):
            obs_t = torch.from_numpy(obs).to(device)                 # (C,H,W)
            mask_t = torch.from_numpy(info["action_mask"].astype(np.float32)).to(device)  # (A,)

            # 同步搜索起点
            sim_env.sync_from(internal_board, to_play, pass_count, last_move)

            # MCTS 得到改良策略 π
            pi = run_mcts(obs_t, mask_t, (to_play == BLACK), agent, sim_env, cfg=mcts_cfg)
            # 采样或贪心
            if cfg["RL"]["sample_action"]:
                a = int(np.random.choice(np.arange(A), p=pi))
            else:
                a = int(np.argmax(pi))

            next_obs, reward, terminated, truncated, next_info = env.step(a)
            done = bool(terminated or truncated)
            ep_return += float(reward)

            # 推进内部Board
            if a == A - 1:
                internal_board.play(to_play, None, to_play=to_play)
                pass_count += 1
                last_move = None
            else:
                r, c = divmod(a, cfg["ENV"]["board_size"])
                internal_board.play(to_play, (r, c), to_play=to_play)
                pass_count = 0
                last_move = (r, c)
            to_play = BLACK if to_play == WHITE else WHITE

            # 写回放
            buf.add(
                o=obs, m=info["action_mask"].astype(np.int8), a=a, r=reward,
                no=next_obs, nm=next_info["action_mask"].astype(np.int8), d=done
            )

            obs, info = next_obs, next_info
            global_step += 1

            # 更新
            if buf.size() >= cfg["RL"]["warmup"] and (global_step % cfg["RL"]["update_every"] == 0):
                batch_np = buf.sample(sac_cfg.batch_size)
                batch = {k: torch.from_numpy(v).to(device) if isinstance(v, np.ndarray) else v for k, v in batch_np.items()}
                stats = agent.update(batch, global_step)
                for k, v in stats.items():
                    logger.add_scalar(f"train/{k}", v, global_step)

            if done:
                break

        logger.add_scalar("train/episode_return", ep_return, ep)

    logger.close()
    env.close()
```

```python
# sac_mcts/envs/symmetry.py
from __future__ import annotations
import numpy as np

# D4 group: rot0, rot90, rot180, rot270, and each with mirror (horizontal flip)
# Index 0..7: r0, r90, r180, r270, fx, fx+r90, fx+r180, fx+r270

def _apply_xy(xy, k, size):
    r, c = xy
    if k % 4 == 0:      # r0
        rr, cc = r, c
    elif k % 4 == 1:    # r90
        rr, cc = c, size - 1 - r
    elif k % 4 == 2:    # r180
        rr, cc = size - 1 - r, size - 1 - c
    else:               # r270
        rr, cc = size - 1 - c, r
    if k >= 4:          # mirror L-R
        cc = size - 1 - cc
    return rr, cc

def transform_obs(obs: np.ndarray, k: int) -> np.ndarray:
    # obs: (C,H,W)
    C, H, W = obs.shape
    out = obs.copy()
    rot = k % 4
    for _ in range(rot):
        out = np.rot90(out, k=1, axes=(1, 2))
    if k >= 4:
        out = np.flip(out, axis=2)
    return out.copy()

def transform_action(a: int, size: int, k: int) -> int:
    if a == size * size:  # pass
        return a
    r, c = divmod(a, size)
    rr, cc = _apply_xy((r, c), k, size)
    return rr * size + cc

def transform_mask(mask: np.ndarray, size: int, k: int) -> np.ndarray:
    # mask: (A,) int/bool; last is pass
    out = np.zeros_like(mask)
    out[-1] = mask[-1]
    coords = np.where(mask[:-1] > 0)[0]
    for a in coords:
        ra = transform_action(int(a), size, k)
        out[ra] = 1
    return out
```

```python
# sac_mcts/core/mcts.py
from __future__ import annotations
import math, numpy as np, torch
from dataclasses import dataclass
from typing import Optional, Dict

@dataclass
class MCTSConfig:
    sims: int = 400
    c_puct: float = 1.5
    dirichlet_alpha: float = 0.3
    dirichlet_eps: float = 0.25
    temperature: float = 1.0
    enable_tactical_bias: bool = True
    capture_boost: float = 1.6
    atari_boost: float = 1.25
    pass_penalty: float = 0.6

class Node:
    def __init__(self, parent: Optional["Node"], prior: float, player_to_move: int):
        self.parent = parent
        self.prior = prior
        self.player = player_to_move    # +1 black, -1 white
        self.N = 0
        self.W = 0.0    # 累计“黑方视角”价值
        self.Q = 0.0
        self.children: Dict[int, Node] = {}
        self.legal = None
        self.is_terminal = False

    def expand(self, priors: np.ndarray, legal_mask: np.ndarray, player_to_move: int):
        self.legal = legal_mask.astype(np.int8)
        s = (priors * self.legal).sum()
        probs = (priors * self.legal) / s if s > 0 else (self.legal / max(1, self.legal.sum()))
        for a, p in enumerate(probs):
            if self.legal[a]:
                self.children[a] = Node(self, float(p), player_to_move)

    def ucb(self, child: "Node", c_puct: float) -> float:
        u = c_puct * child.prior * math.sqrt(self.N + 1e-8) / (1 + child.N)
        return child.Q + u

    def backup(self, v_black: float):
        n = self
        while n is not None:
            n.N += 1
            n.W += v_black
            n.Q = n.W / n.N
            v_black = -v_black
            n = n.parent

def _soft_value_from_critic(model, z, mask):
    q1, q2 = model.critic(z)
    q = torch.min(q1, q2)
    alpha = model.alpha.clamp_min(1e-6)
    very_neg = -1e9
    q_masked = q.masked_fill(mask.unsqueeze(0) == 0, very_neg)
    v = (alpha * torch.logsumexp(q_masked / alpha, dim=-1)).squeeze(0)
    return v

def _tactical_bias(sim_env, legal_mask: np.ndarray, cfg: MCTSConfig) -> np.ndarray:
    """简单战术：吃子>0、打吃（制造对方一口气）。返回乘性权重。"""
    size = sim_env.size
    mult = np.ones_like(legal_mask, dtype=np.float32)
    if legal_mask.sum() <= 1:  # 仅 pass 或无非pass
        return mult
    for a in np.where(legal_mask[:-1] == 1)[0]:
        env2 = sim_env.clone()
        # 合法性已经保证；试着执行并统计吃子/打吃
        env2.step(int(a))
        # 捕获：上一手执行在 env2 的 parent 节点就完成，无法直接得计数；用局部判断近似：若周围对方块被清空数>0
        # 简化：比较落子后邻域对方棋减少近似。这里用 Board 层很重，已在合规动作上，近似用 capture 优先：
        # 我们可用一个更稳妥的启发：若这步不是 pass 且对方邻接少，给 atari 提升
        # 由于 GoSearchEnv 没直接暴露捕获数，此处只做“是否制造打吃”检测（降低复杂度）：
        # 检测：落子后对方任一邻近块的“气==1” => 视为 atari
        atari = False
        r, c = divmod(int(a), size)
        # check neighbors after move
        for nr, nc in ((r-1,c),(r+1,c),(r,c-1),(r,c+1)):
            if 0 <= nr < size and 0 <= nc < size:
                # 近似：如果该点为空则跳过；若是对方子，估气（简化版）：四邻空点数
                v = int(env2.board.grid[nr, nc])
                if v in (1, 2) and v != (1 if env2.to_play==1 else 2):  # 对手颜色
                    # 简化气数：统计该块四邻为空的点个数（低估，但足够用于启发）
                    q = 0
                    for xr, xc in ((nr-1,nc),(nr+1,nc),(nr,nc-1),(nr,nc+1)):
                        if 0 <= xr < size and 0 <= xc < size and env2.board.grid[xr, xc] == 0:
                            q += 1
                    if q == 1:
                        atari = True
                        break
        if atari:
            mult[a] *= cfg.atari_boost
    # 轻度惩罚早期 pass（若存在非 pass 合法手）
    if legal_mask[:-1].sum() > 0 and legal_mask[-1] == 1:
        mult[-1] *= cfg.pass_penalty
    return mult

def run_mcts(root_obs: torch.Tensor,
             root_mask: torch.Tensor,
             root_player_black: bool,
             model,
             sim_env,
             cfg: MCTSConfig) -> np.ndarray:
    device = next(model.parameters()).device
    root = Node(parent=None, prior=1.0, player_to_move=1 if root_player_black else -1)

    with torch.no_grad():
        z = model.encoder(root_obs.unsqueeze(0).to(device))
        logits = model.actor(z)
        priors = torch.log_softmax(
            logits.masked_fill(root_mask.unsqueeze(0).to(device) == 0, torch.finfo(logits.dtype).min), dim=-1
        ).exp().squeeze(0).cpu().numpy()

    legal = root_mask.cpu().numpy().astype(np.int8)

    # 战术偏置 + Dirichlet（仅根注入）
    if cfg.enable_tactical_bias:
        tb = _tactical_bias(sim_env, legal, cfg)
        priors = priors * tb
    if cfg.dirichlet_eps > 0 and legal.sum() > 1:
        alpha = cfg.dirichlet_alpha
        noise = np.random.dirichlet([alpha] * int(legal.sum()))
        mix = priors.copy()
        mix[legal == 1] = (1 - cfg.dirichlet_eps) * priors[legal == 1] + cfg.dirichlet_eps * noise
        priors = mix

    root.expand(priors, legal, root.player)

    for _ in range(cfg.sims):
        node = root
        env = sim_env.clone()
        # selection
        while node.children and not node.is_terminal:
            a = max(node.children.items(), key=lambda kv: node.ucb(kv[1], cfg.c_puct))[0]
            env.step(int(a))
            node = node.children[a]
            node.is_terminal = env.is_terminal()
        # expand & evaluate
        if not node.is_terminal:
            obs = env.obs().unsqueeze(0).to(device)  # (1,C,H,W)
            mask = env.legal_mask().to(device)       # (A,)
            with torch.no_grad():
                z = model.encoder(obs)
                logits = model.actor(z)
                pri = torch.log_softmax(
                    logits.masked_fill(mask.unsqueeze(0) == 0, torch.finfo(logits.dtype).min), dim=-1
                ).exp().squeeze(0).cpu().numpy()
                if cfg.enable_tactical_bias:
                    tb = _tactical_bias(env, mask.cpu().numpy().astype(np.int8), cfg)
                    pri = pri * tb
                v = _soft_value_from_critic(model, z, mask).item()
            node.expand(pri, mask.cpu().numpy().astype(np.int8),
                        1 if env.to_play_is_black() else -1)
        else:
            v = env.final_value_black()
        node.backup(float(v))

    counts = np.array([node.children[a].N if a in node.children else 0
                       for a in range(legal.shape[0])], dtype=np.float32)
    if counts.sum() <= 0:
        pi = legal / max(1, legal.sum())
    else:
        if cfg.temperature == 1.0:
            pi = counts / counts.sum()
        else:
            t = float(cfg.temperature)
            pi = (counts ** (1.0 / t)); pi = pi / pi.sum()
    return pi
```

```python
# sac_mcts/core/sac.py
from __future__ import annotations
import torch, torch.nn as nn, torch.nn.functional as F
from dataclasses import dataclass
from typing import Dict
from .nets import ConvEncoder, CategoricalActor, DoubleQCritic
from .utils import masked_log_softmax, masked_softmax, get_device

@dataclass
class SACConfig:
    gamma: float = 0.997
    lr: float = 3e-4
    tau: float = 0.005
    init_alpha: float = 0.1
    target_entropy_scale: float = 0.98
    batch_size: int = 256
    use_amp: bool = True
    max_grad_norm: float = 5.0

class SACDiscreteAgent(nn.Module):
    def __init__(self, obs_shape, act_dim: int, cfg: SACConfig):
        super().__init__()
        c, h, w = obs_shape
        self.device = get_device()
        self.cfg = cfg
        self.encoder = ConvEncoder(in_channels=c).to(self.device)
        self.actor = CategoricalActor(self.encoder.out_dim, act_dim).to(self.device)
        self.critic = DoubleQCritic(self.encoder.out_dim, act_dim).to(self.device)
        self.critic_tgt = DoubleQCritic(self.encoder.out_dim, act_dim).to(self.device)
        self.critic_tgt.load_state_dict(self.critic.state_dict())
        self.alpha = torch.tensor(cfg.init_alpha, device=self.device, requires_grad=True)

        self.optim_actor = torch.optim.Adam(list(self.encoder.parameters())+list(self.actor.parameters()), lr=cfg.lr)
        self.optim_critic = torch.optim.Adam(self.critic.parameters(), lr=cfg.lr)
        self.optim_alpha = torch.optim.Adam([self.alpha], lr=cfg.lr)
        self.scaler_actor = torch.cuda.amp.GradScaler(enabled=(self.device.type=="cuda" and cfg.use_amp))
        self.scaler_critic = torch.cuda.amp.GradScaler(enabled=(self.device.type=="cuda" and cfg.use_amp))

    @torch.no_grad()
    def act_greedy(self, obs_t, mask_t) -> int:
        self.eval()
        z = self.encoder(obs_t.unsqueeze(0))
        logits = self.actor(z)
        probs = masked_softmax(logits, mask_t.unsqueeze(0), dim=-1).squeeze(0)
        return int(torch.argmax(probs).item())

    def soft_value(self, q: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        alpha = self.alpha.clamp_min(1e-6)
        very_neg = -1e9
        q_masked = q.masked_fill(mask == 0, very_neg)
        return alpha * torch.logsumexp(q_masked / alpha, dim=-1)

    def update(self, batch: Dict[str, torch.Tensor], step: int) -> Dict[str, float]:
        obs = batch["obs"].to(self.device)            # (B,C,H,W)
        mask = batch["mask"].to(self.device).float()  # (B,A)
        act = batch["act"].to(self.device).long()     # (B,)
        rew = batch["rew"].to(self.device).float()    # (B,)
        next_obs = batch["next_obs"].to(self.device)
        next_mask = batch["next_mask"].to(self.device).float()
        done = batch["done"].to(self.device).float()

        # ---- Critic ----
        with torch.cuda.amp.autocast(enabled=self.scaler_critic.is_enabled()):
            z = self.encoder(obs)
            z_next = self.encoder(next_obs).detach()
            q1, q2 = self.critic(z)
            with torch.no_grad():
                q1_t, q2_t = self.critic_tgt(z_next)
                q_t = torch.min(q1_t, q2_t)
                v_next = self.soft_value(q_t, next_mask)
                target_q = rew + (1.0 - done) * self.cfg.gamma * v_next  # (B,)
            q1_a = q1.gather(1, act.view(-1,1)).squeeze(1)
            q2_a = q2.gather(1, act.view(-1,1)).squeeze(1)
            loss_q = F.mse_loss(q1_a, target_q) + F.mse_loss(q2_a, target_q)

        self.optim_critic.zero_grad(set_to_none=True)
        self.scaler_critic.scale(loss_q).backward()
        if self.cfg.max_grad_norm is not None:
            self.scaler_critic.unscale_(self.optim_critic)
            torch.nn.utils.clip_grad_norm_(self.critic.parameters(), self.cfg.max_grad_norm)
        self.scaler_critic.step(self.optim_critic)
        self.scaler_critic.update()

        # ---- Actor ----
        with torch.cuda.amp.autocast(enabled=self.scaler_actor.is_enabled()):
            # encoder 共享，按常见做法对 actor 也回传 encoder 梯度（已在 optim_actor 参数中）
            z_pi = self.encoder(obs)
            logits = self.actor(z_pi)
            logp = masked_log_softmax(logits, mask, dim=-1)
            probs = logp.exp()
            with torch.no_grad():
                q1_pg, q2_pg = self.critic(z_pi)
                q_pg = torch.min(q1_pg, q2_pg)
            alpha = self.alpha.clamp_min(1e-6)
            loss_pi = (probs * (alpha * logp - q_pg)).sum(dim=-1).mean()
            ent = (-probs * logp).sum(dim=-1).mean()

        self.optim_actor.zero_grad(set_to_none=True)
        self.scaler_actor.scale(loss_pi).backward()
        if self.cfg.max_grad_norm is not None:
            self.scaler_actor.unscale_(self.optim_actor)
            torch.nn.utils.clip_grad_norm_(list(self.encoder.parameters())+list(self.actor.parameters()),
                                           self.cfg.max_grad_norm)
        self.scaler_actor.step(self.optim_actor)
        self.scaler_actor.update()

        # ---- Alpha ----
        with torch.no_grad():
            target_H = self.cfg.target_entropy_scale * torch.log(mask.sum(dim=-1).clamp_min(1)).float()
        loss_alpha = -(self.alpha * ((logp * probs).sum(dim=-1).detach() + target_H)).mean()
        self.optim_alpha.zero_grad(set_to_none=True)
        loss_alpha.backward()
        self.optim_alpha.step()

        # ---- Soft update ----
        with torch.no_grad():
            for p, pt in zip(self.critic.parameters(), self.critic_tgt.parameters()):
                pt.data.mul_(1 - self.cfg.tau).add_(self.cfg.tau * p.data)

        q_mean = (q1_a.detach().mean() + q2_a.detach().mean()).item() / 2.0
        return dict(loss_q=float(loss_q.item()),
                    loss_pi=float(loss_pi.item()),
                    loss_alpha=float(loss_alpha.item()),
                    alpha=float(self.alpha.item()),
                    entropy=float(ent.item()),
                    q_mean=float(q_mean))
```

```python
from __future__ import annotations
import torch, numpy as np, random

def get_device() -> torch.device:
    return torch.device("cuda") if torch.cuda.is_available() else torch.device("cpu")

def set_seed(seed: int):
    random.seed(seed); np.random.seed(seed)
    torch.manual_seed(seed); torch.cuda.manual_seed_all(seed)

def masked_log_softmax(logits: torch.Tensor, mask: torch.Tensor, dim: int=-1) -> torch.Tensor:
    very_neg = torch.finfo(logits.dtype).min
    return torch.log_softmax(logits.masked_fill(mask==0, very_neg), dim=dim)

def masked_softmax(logits: torch.Tensor, mask: torch.Tensor, dim: int=-1) -> torch.Tensor:
    return masked_log_softmax(logits, mask, dim).exp()

def to_tensor(x, device):
    if isinstance(x, np.ndarray): return torch.from_numpy(x).to(device)
    return torch.as_tensor(x, device=device)
```

```python
    os.makedirs(os.path.dirname(path), exist_ok=True)
    torch.save({
        "step": step, "episode": ep, "cfg": cfg,

        "actor": agent.actor.state_dict(),

def train_loop(cfg: Dict[str, Any], agent_bundle, run_name: str = "run"):
    device = get_device()
    set_seed(cfg["SEED"])

    env = gym.make("go-v1", board_size=cfg["ENV"]["board_size"], komi=cfg["ENV"]["komi"])
    obs, info = env.reset(seed=cfg["SEED"])
    C, H, W = obs.shape
    A = info["action_mask"].shape[0]

    agent = agent_bundle.model
    sac_cfg = agent_bundle.sac_cfg
    mcts_cfg = agent_bundle.mcts_cfg
    agent.train()

    buf = ReplayBuffer(cfg["RL"]["buffer_size"], obs_shape=(C, H, W), act_dim=A)
    logger = TBLogger(cfg["LOG"]["logdir"])
    ckpt_dir = os.path.join(cfg["LOG"]["logdir"], "checkpoints")

    sim_env = GoSearchEnv(size=cfg["ENV"]["board_size"], komi=cfg["ENV"]["komi"])
    internal_board = Board(cfg["ENV"]["board_size"], allow_suicide=False, use_superko=False)
    to_play = BLACK; pass_count = 0; last_move = None

    global_step = 0
    for ep in range(cfg["RL"]["episodes"]):
        obs, info = env.reset(seed=cfg["SEED"] + ep)
        internal_board = Board(cfg["ENV"]["board_size"], allow_suicide=False, use_superko=False)
        to_play = BLACK; pass_count = 0; last_move = None
        ep_return = 0.0; ep_len = 0

        for t in trange(cfg["RL"]["max_steps"], desc=f"Ep {ep}", leave=False):
            obs_t  = torch.from_numpy(obs).to(device)
            mask_t = torch.from_numpy(info["action_mask"].astype(np.float32)).to(device)

            sim_env.sync_from(internal_board, to_play, pass_count, last_move)
            pi = run_mcts(obs_t, mask_t, (to_play==BLACK), agent, sim_env, cfg=mcts_cfg)
            a = int(np.random.choice(np.arange(A), p=pi)) if cfg["RL"]["sample_action"] else int(np.argmax(pi))

            next_obs, reward, terminated, truncated, next_info = env.step(a)
            done = bool(terminated or truncated)
            ep_return += float(reward); ep_len += 1

            # advance internal board
            if a == A - 1:  # pass
                internal_board.play(to_play, None, to_play=to_play); pass_count += 1; last_move = None
            else:
                r, c = divmod(a, cfg["ENV"]["board_size"])
                internal_board.play(to_play, (r, c), to_play=to_play); pass_count = 0; last_move = (r, c)
            to_play = BLACK if to_play == WHITE else WHITE

            # write replay (with symmetry aug)
            buf.add(
                o=obs, m=info["action_mask"].astype(np.int8), a=a, r=reward,
                no=next_obs, nm=next_info["action_mask"].astype(np.int8), d=done
            )
            K = int(cfg["AUG"].get("symmetry_k", 0))
            if K > 0:
                size = cfg["ENV"]["board_size"]
                for _ in range(K):
                    k = np.random.randint(0, 8)
                    aug_o  = transform_obs(obs, k)
                    aug_no = transform_obs(next_obs, k)
                    aug_m  = transform_mask(info["action_mask"], size, k)
                    aug_nm = transform_mask(next_info["action_mask"], size, k)
                    aug_a  = transform_action(a, size, k)
                    buf.add(o=aug_o, m=aug_m.astype(np.int8), a=aug_a, r=reward,
                            no=aug_no, nm=aug_nm.astype(np.int8), d=done)

            obs, info = next_obs, next_info
            global_step += 1

            # updates
            if buf.size() >= cfg["RL"]["warmup"] and (global_step % cfg["RL"]["update_every"] == 0):
                batch_np = buf.sample(sac_cfg.batch_size)
                batch = {k: torch.from_numpy(v) if isinstance(v, np.ndarray) else v for k, v in batch_np.items()}
                stats = agent.update(batch, global_step)
                for k, v in stats.items():
                    logger.add_scalar(f"train/{k}", v, global_step)
                # also log root-π entropy as a proxy of exploration
                logger.add_scalar("train/root_pi_entropy",
                                  float(-(pi[pi>1e-12]*np.log(pi[pi>1e-12])).sum()), global_step)

            if done: break

        logger.add_scalar("train/episode_return", ep_return, ep)
        logger.add_scalar("train/episode_len", ep_len, ep)

        # periodic eval (actor greedy only)
        if (ep+1) % int(cfg["EVAL"]["every_episodes"]) == 0:
            score = eval_episode("go-v1", agent, board_size=cfg["ENV"]["board_size"],
                                 komi=cfg["ENV"]["komi"], seed=cfg["SEED"]+1000+ep)
            logger.add_scalar("eval/greedy_return", score, ep)

        # periodic checkpoint
        if (ep+1) % int(cfg["CKPT"]["every_episodes"]) == 0:
            _save_ckpt(os.path.join(ckpt_dir, f"ep_{ep+1}.pth"), agent, global_step, ep+1, cfg)

    logger.close(); env.close()
```

### Notes & tips

*   **速度**：MCTS 带战术偏置≠硬编码规则，只是对 Actor 先验做**乘性微调**；如需更“纯粹”，将 `enable_tactical_bias=false`。
*   **稳定性**：AMP+grad-clip 在 9×9 上很友好。若出现 NaN，先把 `use_amp:false`、`lr` 减半。
*   **对称增强**：`symmetry_k` 推荐 1~4；过大将放慢训练。
*   **评测**：`eval/greedy_return` 是**对随机对手**的胜负值（黑胜+1/白胜-1/和0）；想对 UCT 评测可复用你之前的 `selfplay_uct.py`。
